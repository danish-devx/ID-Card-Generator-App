# 🪪 ID Card Generator App

A modern and responsive **ID Card Generator** built using HTML, CSS, and JavaScript.  
This application allows users to enter personal details, upload an image, and instantly generate a professional-looking ID card.

🔗 Live Demo: https://danish-devx.github.io/ID-Card-Generator-App/

---

## 🚀 Features

- 🧾 User-friendly form to input personal details
- 🖼️ Image upload with instant preview
- 🎨 Modern UI (Neumorphism + Gradient Theme)
- 📱 Fully responsive design (Mobile + Desktop)
- ⚡ Real-time ID card generation
- 🔢 Input validation (e.g., phone number limit)
- 🎯 Clean and minimal design

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Neumorphism + Responsive Design)
- JavaScript (DOM Manipulation)

---

## 📸 How It Works

1. Enter your personal details (Name, Email, Phone, etc.)
2. Upload your profile image
3. Click on **Generate**
4. Your ID Card will be created instantly
